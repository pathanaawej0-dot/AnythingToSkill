# Design (Glean System)

## Theme
Midnight Minimalist. Inspired by glean.aawej.in. High contrast, deep midnight backgrounds, and crisp typography.

## Palette
All values in OKLCH.

### Foundation
- `--bg`: oklch(0.08 0.02 260) — Deep midnight (rgb(5, 8, 16))
- `--surface`: oklch(0.12 0.02 260) — Dark surface
- `--ink`: oklch(0.96 0.01 260) — Crisp off-white (rgb(240, 244, 255))
- `--muted`: oklch(0.60 0.02 260) — Subdued blue-gray

### Brand
- `--brand-primary`: oklch(0.55 0.20 260) — Glean Blue
- `--brand-accent`: oklch(0.55 0.20 260) — Consistent primary accent

## Typography
- **Display**: Satoshi (or sans-serif) — Large, bold, tracking-tight.
- **Body**: Satoshi (or sans-serif) — Regular, 1.6 line-height.
- **Mono**: Geist Mono — For code blocks.

## Components
- **Navbar**: Transparent with backdrop blur, minimal text links (no uppercase/dots).
- **Cards**: Minimal borders (1px oklch(0.15 0.02 260)), no heavy shadows unless hovered.
- **Buttons**: Pill-shaped or small-radius, high contrast.
- **Docs**: Clean sidebar on the left, clear reading measure.

## Layout
- **Hero**: Center-aligned or side-by-side with subtle background glows.
- **Spacing**: Generous, breathable.
