Set up the Next.js project in `web/` with Tailwind CSS and build the home page. The home page should:

- Hero section explaining AnythingToSkill with animated terminal-style demo
- Copyable install command: `npx skills add pathanaawej0-dot/AnythingToSkill`

- Input source showcase (YT, URL, code, text)

- Responsive, dark-themed, mobile-friendly
