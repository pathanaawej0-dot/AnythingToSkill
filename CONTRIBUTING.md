# Contributing to AnythingToSkill

Thank you for considering contributing! We welcome contributions of all kinds: bug reports, feature requests, documentation improvements, and code changes.

## How to contribute

1. **Check existing issues** — see `.scratch/` or the GitHub issue tracker for open work.
2. **Fork the repository** and create a branch from `main`.
3. **Make your changes** following the project conventions:
   - Keep SKILL.md concise — use reference files for detail
   - Follow the domain vocabulary in `CONTEXT.md`
   - Respect existing ADRs in `docs/adr/`
4. **Test your changes** — for skill changes, run a smoke test with the agent.
5. **Submit a pull request** with a clear description of what you changed and why.

## Development setup

```bash
git clone https://github.com/pathanaawej0-dot/AnythingToSkill.git
cd AnythingToSkill
```

## Code of conduct

Be respectful, constructive, and inclusive. Harassment and discriminatory behavior will not be tolerated.

## Reporting issues

File issues at https://github.com/pathanaawej0-dot/AnythingToSkill/issues with:
- A clear title and description
- Steps to reproduce (if bug)
- Expected vs actual behavior
- Agent and version you're using
